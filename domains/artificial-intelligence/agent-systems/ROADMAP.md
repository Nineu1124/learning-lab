# Agent Systems Roadmap

## Stage 1：基础模型

Message、Context、Streaming、Structured Output 与 Tool Calling。

## Stage 2：Agent Loop

Model Adapter、Tool Registry、Loop State、Stop Policy、Permission 与 Recovery。

## Stage 3：Agent Harness

比较 Codex、Claude Code、OpenCode 与 DeepSeek 相关实现，研究会话、工具、权限、沙箱和事件协议。

## Stage 4：Agent Runtime

Session、Turn、Runtime Adapter、Event Normalization、Cancellation、Replay 与 Observability。

## Stage 5：真实项目

通过 Tsukiori、Evidence Research Agent 和 Harness Benchmark 验证理解。
