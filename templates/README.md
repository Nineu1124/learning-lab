# Templates

新增学习分支时至少包含：

```text
track/
├─ README.md
├─ ROADMAP.md
├─ PROGRESS.md
├─ GLOSSARY.md
├─ concepts/
├─ labs/
├─ case-studies/
└─ projects/
```

优先使用简单 Markdown。只有真实需要运行代码时，才为对应 Lab 或 Project 添加语言工具链。

## 学习记录模板

- [session-record.md](session-record.md)：唯一正式的 Course Day / 对话式学习提交模板，包含到期回忆、Prediction、错误变式、Evidence、验收、Capability / Retention 判断和复习调度。
- [weekly-review.md](weekly-review.md)：默认每七个 Course Session 使用的限时、闭卷、混合检验模板。
- [learning-commit.md](learning-commit.md)：通过与未通过 Session 的 Commit message、提交文件范围和检查模板。
- [daily-log.md](daily-log.md)：没有正式 Course Day 时的轻量手记，不能单独证明 Day completed、Capability 晋级或 Retention。
- [lab-report.md](lab-report.md)：独立 Lab 的实验说明。

反思和学习者第一次回答必须由学习者先写并保留原文。模板的执行依据见 [Learning Method](../learning-system/LEARNING-METHOD.md)，到期项目统一维护在 [Review Queue](../REVIEW-QUEUE.md)。不要同时维护两份内容重叠的正式每日记录。

正式记录必须保留 Outcome、到期闭卷回答、第一次 Prediction / Attempt、一个错误或边界及变式、Transfer、可复现 Evidence、学习者总结、Session / Capability / Retention 决策、Queue 更新和唯一 Next Action。精确时长、完整环境、Issue 和长日志是条件字段；无关时写 `None` 或省略说明，不为填模板制造内容。
